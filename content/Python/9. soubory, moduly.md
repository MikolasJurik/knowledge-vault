
## 1. Souborový systém a cesty

```text
Unix:    /  ── home ── krtecek ── Pictures ── funny_cat.gif
Windows: C:\ ── Users ── Krtecek ── Pictures ── funny_cat.gif
```

| Pojem | Unix (Linux / macOS) | Windows | Poznámka |
| :--- | :--- | :--- | :--- |
| **Kořen (root)** | `/` | `C:\`, `D:\` | Nejvyšší adresář v systému |
| **Domovský adresář** | `/home/krtecek` (`~`) | `C:\Users\Krtecek` | Výchozí složka uživatele |
| **Oddělovač složek** | `/` | `\` | V Pythonu `\` escapovat (`'C:\\...'`) nebo raw string (`r'C:\...'`) |
| **Absolutní cesta** | `/home/krtecek/a.txt` | `C:\Users\Krtecek\a.txt` | Začíná v kořeni |
| **Relativní cesta** | `Pictures/a.txt` | `Pictures\a.txt` | Začíná v aktuálním adresáři (**CWD**) |
| **Speciální znaky** | `.` (tato složka), `..` (o složku výš) | `.`, `..` | Např. `../../etc` jde o 2 úrovně výš |

**Základní CLI příkazy:** `pwd`  (vypiš CWD) · `ls`  (obsah složky) · `cd PATH` (změň složku)

## 2. Modul `pathlib` (doporučený způsob práce s cestami)

Maže rozdíly mezi Unixem a Windows. Základní třída `Path`.

```python
from pathlib import Path

# Tvorba a spojování cest (operátor / automaticky doplní správný oddělovač)
p = Path('/home/krtecek/Pictures/funny_cat.gif')
p2 = Path.home() / 'Pictures' / 'funny_cat.gif'   # ~ / Pictures / funny_cat.gif
cwd = Path.cwd()                                   # Aktuální pracovní adresář

# Převod relativní -> absolutní
Path('../../cat.gif').absolute()   # Ponechá '..' v cestě
Path('../../cat.gif').resolve()    # Vyhodnotí '..' a vrátí čistou kanonickou cestu
```

### Části cesty a dotazování
Pro `p = Path('/home/krtecek/Pictures/funny_cat.gif')`:

| Vlastnost / Metoda | Výstup | Význam |
| :--- | :--- | :--- |
| `p.parent` | `Path('/home/krtecek/Pictures')` | Nadřazený adresář (lze řetězit: `.parent.parent`) |
| `p.name` | `'funny_cat.gif'` | Název souboru včetně přípony |
| `p.stem` | `'funny_cat'` | Název souboru **bez** přípony |
| `p.suffix` | `'.gif'` | Přípona souboru |
| `p.parts` | `('/', 'home', 'krtecek', ...)` | N-tice všech částí cesty |
| `p.is_absolute()` | `True` / `False` | Je cesta absolutní? |
| `p.exists()` | `True` / `False` | Existuje soubor/složka na disku? |
| `p.is_file()` / `p.is_dir()` | `True` / `False` | Existuje a je to normální soubor / adresář? |

### Procházení adresářů a manipulace
```python
p = Path('.')

# Výpis obsahu (vždy obalit do sorted() - pořadí není garantované!)
for f in sorted(p.iterdir()): ...         # Projde všechny soubory v cwd (current working directory)
for f in sorted(p.glob('*.pdf')): ...     # to stejne ale navic podle vzoru: * (0+ znaků), ? (1 znak), [bm] (výčet)
for f in sorted(p.rglob('*.png')): ...    # Rekurzivně i v podadresářích

# Manipulace se systémem
d = Path('data/new_dir')
d.mkdir(exist_ok=True)                    # Vytvoří složku (nespadne, pokud už existuje)
Path('a.gif').replace(d / 'b.gif')        # Přesune / přejmenuje soubor
Path('a.jpg').unlink(missing_ok=True)     # Smaže soubor
d.rmdir()                                 # Smaže PRÁZDNOU složku
```

### Doplňky: `shutil` a `os`
* **`shutil`** – pokročilé operace nad soubory a celými stromy složek:
  * `shutil.copy(src, dst)` – zkopíruje soubor
  * `shutil.copytree(src, dst)` – zkopíruje celou složku včetně obsahu
  * `shutil.rmtree('stuff')` – **smaže složku i se vším uvnitř**
  * `shutil.make_archive('archiv', 'zip', 'slozka')` – zkomprimuje do ZIPu
* **`os`** – většinou zastaralé oproti `pathlib`, užitečné pro `os.chdir('cesta')` (změna CWD), `os.cpu_count()`, `os.getenv('USER')`.

## 3. Čtení a zápis souborů

> [!tip] Zlaté pravidlo: vždy používej `with` a `encoding='utf8'`
> Blok `with` soubor bezpečně zavře (uloží změny) i v případě výjimky. Po opuštění bloku už se souborem nelze pracovat.

```python
with open('data/soubor.txt', mode='r', encoding='utf8') as f:
    text = f.read()
```

### Módy otevření (`mode`)
| Mód | Účel | Soubor existuje | Soubor neexistuje |
| :--- | :--- | :--- | :--- |
| `'r'` | Čtení *(výchozí)* | Čte od začátku | `FileNotFoundError` |
| `'w'` | Zápis | **Přemaže obsah** a píše od začátku! | Vytvoří nový |
| `'a'` | Přidání (*append*) | Píše na konec souboru | Vytvoří nový |
| `'x'` | Exkluzivní zápis | `FileExistsError` | Vytvoří nový |
| `'r+'` / `'w+'` | Čtení i zápis | Čte od začátku / **Přemaže** | Chyba / Vytvoří nový |
| `'rb'`, `'wb'`, ... | Binární režim | Pracuje s typem `bytes` místo `str` | Dle módu výše |

> [!warning] Kódování a bílé znaky
> - **Kódování:** Soubor je vždy jen posloupnost bajtů. Nesoulad (např. `cp1250` čtené jako `cp1252` nebo `utf8`) rozbije diakritiku. Kódování zjišťuje `locale.getpreferredencoding()`.
> - **Konce řádků:** Řádky končí `\n` (Windows `\r\n`, Python to automaticky převádí na `\n`). Při čtení řádků proto odstraňuj `\n` pomocí `.rstrip()`.

### Způsoby čtení a zápisu
```python
# --- ČTENÍ ---
text = f.read()                  # Celý soubor jako str (nebo f.read(20) = 20 znaků)
line = f.readline().rstrip()     # Jeden řádek (na konci souboru vrací '')
lines = f.readlines()            # Všechny řádky jako list[str]
for line in f:                   # Nejlepší pro velké soubory (iteruje po řádcích)
    print(line.rstrip())

# Zkratka přes Path (samo otevře a zavře):
text = Path('a.txt').read_text(encoding='utf8')

# --- ZÁPIS ---
f.write('Alice\n')               # Zapíše přesně str (nevkládá \n samo!), vrátí počet znaků
print('Alice', 10, file=f)       # Přesměrování print() do souboru
Path('a.txt').write_text('ahoj', encoding='utf8')  # Zkratka přes Path

# --- VÍCE SOUBORŮ A SPECIÁLNÍ OBJEKTY ---
with open('a.txt') as fa, open('b.txt', 'w') as fb: ...
# sys.stdin (vstup), sys.stdout (výstup), sys.stderr (chybový výstup)
```

### Binární soubory & Ošetření chyb (EAFP)
- **Konverze `str` ↔ `bytes`:** `'věta'.encode('utf8')` → `bytes` | `b'...'.decode('utf8')` → `str`
- **Otevírání s `try-except`** (*Ask for forgiveness, not for permission* – neptáme se předem `exists()`, rovnou zkoušíme otevřít):
```python
try:
    with open('neexistuje.txt', encoding='utf8') as f:
        print(f.read())
except FileNotFoundError:
    print('Soubor neexistuje.')
except PermissionError:
    print('Nemáš právo číst soubor.')
except OSError:                  # Obecnější předek FileNotFoundError i PermissionError
    print('Chyba při otevírání.')
```

## 4. Moduly, balíčky a `pip`

- **Modul** = jeden `.py` soubor s funkcemi a proměnnými.
- **Balíček (*package*)** = složka obsahující více modulů (např. `os.path`, `my_modules.areas`).
- **Zdroje:** Standardní knihovna → PyPI (`pip`) → Vlastní `.py` soubory.

### Importování a spouštění
```python
import math                             # Použití: math.pi, math.cos(0)
import numpy as np                      # Alias: np.linspace(0, 1, 11)
from math import factorial, pi          # Přímo do jmenného prostoru: pi
from math import factorial as fact      # Přejmenování: fact(6)
from my_modules import areas            # Vlastní modul ze složky my_modules
```
Spuštění modulu z příkazového řádku: `python -m nazev_modulu` (např. `python -m my_modules.fibonacci` nebo `python -m doctest`).

### Správa balíčků (`pip` a `venv`)
```bash
python -m pip install numpy      # Instalace balíčku (vždy přes -m v terminálu)
python -m pip show numpy         # Verze a info | list (seznam) | help
# Virtuální prostředí (pokud není oprávnění instalovat globálně):
python -m venv ~/venv && . ~/venv/bin/activate
```

### Struktura skriptu a `if __name__ == '__main__':`
Kód v bloku `if __name__ == '__main__':` se spustí **pouze při přímém spuštění souboru** (npř srz python muj_skript.py), nikoliv při jeho importu do jiného skriptu (při importu je `__name__` rovno názvu modulu). → k testování 

```python
"""Docstring: co modul dělá."""
import math                      # 1. Importy
KONSTANTA = 42                   # 2. Konstanty

def pomocna_fce(): ...           # 3. Funkce
def main(): ...                  # 4. Hlavní logika

if __name__ == '__main__':       # 5. Vstupní bod skriptu
    main()
```
→ Zde se main() spustí jen pos puštění origo skriptu, už se ale nespustí když tento skript naimportuju do jiného skrtiptu (musím zde zavolat main() pokud chcu aby se spustila)

.get se douč pro dict

seskupení 2 listů do dicty tak aby se hodnoty jež maj stejné klíče sečetly:
```python
klice = ["a", "b", "a", "c", "b"]
hodnoty = [10, 20, 5, 100, 30]

soucty = {}
for klic, hodnota in zip(klice, hodnoty):
    soucty[klic] = soucty.get(klic, 0) + hodnota

print(soucty)
# Výstup: {'a': 15, 'b': 50, 'c': 100}
```
