
## 1. Druhy chyb
- **Syntaktické** (`SyntaxError`, `IndentationError`, `TabError`) – program se vůbec nespustí (chybné závorky, odsazení apod.).
- **Výjimky (Runtime)** – nastanou za běhu, lze je zachytit a ošetřit.
- **Systematické (Logické)** – kód běží bez chyb, ale dělá něco jiného, než chceme.

---

## 2. Běžné vestavěné výjimky
| Výjimka               | Příčina                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `NameError`           | Použití nedefinované proměnné                                                                                       |
| `TypeError`           | Operace na nekompatibilním datovém typu (např. `'a' + 5`)                                                           |
| `ValueError`          | Správný typ, ale neplatná hodnota (např. `int('abc')`)                                                              |
| `ZeroDivisionError`   | Dělení nulou                                                                                                        |
| `IndexError`          | Index mimo rozsah seznamu/sekvence                                                                                  |
| `KeyError`            | Hledaný klíč není ve slovníku                                                                                       |
| `RecursionError`      | Překročení limitu rekurze (zacyklení)                                                                               |
| `StopIteration`       | Vyčerpání iterátoru (funkcí `next()`)                                                                               |
| `NotImplementedError` | Metoda/funkce zatím není naimplementována                                                                           |
| `OverflowError`       | numerical operation produces a value that is too large (or too small) to be represented by the underlying data type |

## 3. Ošetření a vyvolání výjimek

### Blok `try – except – else – finally`
```python
try:
    x = 1 / val
except ZeroDivisionError as err:
    print(f"Chyba: {err}")
except (TypeError, ValueError):
    # Lze odchytit více výjimek najednou
    pass
else:
    # Provede se POUZE, pokud žádná výjimka nenastala
    print("Úspěch")
finally:
    # Provede se VŽDY (i při chybě nebo returnu)
    print("Úklid")
```

### Vyvolání výjimky (`raise`)
- `raise ValueError("Záporné číslo!")` – explicitní selhání a ukončení.
- Samostatné `raise` uvnitř `except` bloku předá zachycenou výjimku dál nahoru.
- *Rozdíl:* `return` vrací hodnotu (úspěch), `raise` vyhazuje výjimku (selhání).

## 4. `assert`
Slouží k ověření interních předpokladů (sanity check).
```python
assert x >= 0, "x nesmí být záporné"  # Při False vyvolá AssertionError
```
> [!warning]
> Příkazem `python -O skript.py` se všechny `assert` zcela ignorují (optimalizace).

## 5. Testování

### `doctest`
= otestuje to funkci na vzorové vstupy a výstupy napsané přímo v docstringu
Testy psané přímo v docstringu funkce napodobující interaktivní konzoli (`>>>`).
```python
def inc(x: int) -> int:
    """
    >>> inc(2)
    3
    """
    return x + 1

if __name__ == "__main__":
    import doctest
    doctest.testmod()
```
- **Spuštění z CLI:** `python -m doctest -v skript.py` → před spuštěním doctestu musím vždy kód uložit aby se doctest testoval na součas verzi !!!
- *Pozor:* u čísel typu `float` je kvůli zaokrouhlování nutné použít např. `round()`.

### `pytest`
- Automaticky spouští testy v souborech `test_*.py`.
- Využívá běžný příkaz `assert`.
- **Parametrizace:**
```python
import pytest

@pytest.mark.parametrize("inp, expected", [("3+5", 8), ("2*3", 6)])
def test_eval(inp, expected):
    assert eval(inp) == expected
```

## 6. Nástroje
- **`mypy` (statická typová kontrola):** Kontrola typových anotací bez spuštění kódu:
  ```bash
  python -m mypy skript.py
  ```
- **VS Code Debugger:**
  - `F9` – breakpoint (červený bod)
  - `F5` – spustit debug
  - `Step Over` (další řádek) / `Step Into` (vnořit do funkce) / `Step Out` (ven z funkce)
